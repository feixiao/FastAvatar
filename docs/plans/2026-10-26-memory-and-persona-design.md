# 桌面语音伴侣 — 统一记忆底座与多模态人格引擎设计方案

本文档记录 FastAvatar / Avatar 桌面语音伴侣的**统一记忆系统（Memory Vault）**与**多模态人格卡槽引擎（Persona Slots Engine）**的设计规范与落地细节。

---

## 一、 系统目标与核心底线

1. **零对话延迟损耗 (Latency Invariant)**：
   - 记忆召回与 System Prompt 组装在 Go 内存中完成，耗时严格控制在 **< 2ms**，绝不增加端到端首包发音时延 (TTFA)。
2. **纯 Go 单二进制本地化 (Zero External DB)**：
   - 不依赖任何外部向量数据库服务。所有记忆与人格数据持久化存储于 `~/.avatar/memory.json` 和 `~/.avatar/personas.json`，结构透明，支持用户随时查看、修改与删除。
3. **记忆统一，人格即插即用 (Unified Memory, Pluggable Personas)**：
   - 记忆跟人走，无论切换到哪个角色（幕僚/伴侣/毒舌），底层对用户的认知完全共享，但各角色说话语气、语速音色与关注点截然不同。
4. **口语直控 + 可视化管理 (Dual Control)**：
   - 支持口语快速指令（如“*记住我喜欢喝冰美式*”、“*忘掉刚才那件事*”、“*切换成伴侣模式*”），Go 拦截器在 0.1ms 内直接生效。
   - 前端悬浮胶囊支持一键打开可视化抽屉面板进行增删改查。

---

## 二、 统一记忆底座 (Memory Vault) 设计

### 2.1 双层记忆数据模型
1. **核心画像 (Core Profile)**：
   - 形式：Key-Value 长期事实。
   - 分类：`identity`（身份/称呼）、`preference`（偏好/禁忌）、`habit`（习惯/作息）。
   - 规则：常驻内存，对话时全量注入 System Prompt（保持简练，约 200 字内）。
2. **情景记忆 (Episodic Logs)**：
   - 形式：时间戳 + 语义标签 (Tags) + 事实描述。
   - 规则：对话时根据用户当前 Query 提取标签与关键词，按时间衰减打分召回 Top-3 相关事件注入上下文。

### 2.2 读写时序与异步提炼
- **对话时（实时读路径，< 2ms）**：
  - 核心画像 + Top-3 情景记录直接由内存组装成提示词前缀。
- **对话后（后台异步写路径）**：
  - TTS 发音完毕、伴侣回到 Idle 状态后，后台 Goroutine 静默调用轻量模型判断是否有新的画像事实或重要情景，进行去重更新。

## 三、 人格卡槽引擎 (Persona Slots Engine) 设计

### 3.1 人格卡槽结构
系统预置三大经典卡槽，并支持用户无限自定义添加：
1. **💼 幕僚模式 (Jarvis)**：干练、极简、聚焦效率，语速偏快（1.2x）。
2. **🌙 知心伴侣 (Companion)**：温和、共情、聚焦情绪与生活，语速自然（1.0x）。
3. **🔥 毒舌损友 (Roaster)**：犀利、幽默、拒绝套话与鸡汤，语速轻快（1.1x）。

### 3.2 三维流转机制
1. **手动点击切换**：胶囊状态栏上直观展示当前人格徽章（如 `💼` / `🌙` / `🔥`），点击一键轮转。
2. **口语指令切换**：用户说出“*切换成/变成 + 人格名称*”，Go 拦截器 0.1ms 识别并切换，直接播报语音确认“*已切换为伴侣模式*”。
3. **时段自动流转 (Time Scheduler)**：
   - 9:00 - 18:00：自动启用「幕僚模式」。
   - 18:00 - 24:00：自动流转为「知心伴侣」。
   - 24:00 - 9:00：沉睡微弱呼吸，自动转为夜间轻语。
   - 用户手动切换后，可选择“今日锁定”或“跟随日程自动流转”。

### 3.3 亲密度与关系进阶 (Bond Progression)
- 每次有效交互获得 10 XP，连续多天相伴触发 Streak 连击倍率。
- 阶段划分：`Lv.1 初识` ➔ `Lv.2 熟络` ➔ `Lv.3 知己` ➔ `Lv.4 羁绊` ➔ `Lv.5 莫逆`。
- 等级直接作为上下文注入 Prompt，伴侣在不同阶段的措辞与语气随之自然演化。
