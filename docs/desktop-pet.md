# Desktop Pet 🐋 (macOS 桌面宠物与实时语音伴侣)

> 参考 Agora Desktop Pet Recipe 规范实现的 macOS 轻量悬浮桌宠与全双工可打断实时语音互动系统。

常驻在 macOS 屏幕角落的灵动桌面宠物：支持吃大米饭与抱钢盆干饭动画、逗弄小草、闲聊唠嗑、摸头加好感度，嘴型随声音自然张合，而且说话随时能插话打断。

桌宠形象与人设**完全解耦且自由可替换**：既支持原汁原味的大肥鱼（鲸鱼娘），也无缝支持橘宝喵、灵狐小九、星灵露露及自定义导入的标准 Codex Pet 图集皮肤。

## 🎮 桌面本地零网络互动 (Play Together)

在没有配置大模型 API Key 或完全断网的物理隔离环境下，桌宠依然支持完整的本地交互与动作状态机：

1. **拖拽移动 (Move Anywhere)**：按住桌宠舞台任意位置直接拖动，窗口支持平滑跟随。
2. **摸摸头与戳戳 (Touch & Poke)**：
   * 单击桌宠：触发好奇歪头与眨眼；
   * 双击桌宠 / 快捷栏摸摸头：触发跳跃爱心粒子与羁绊好感度提升（`+5 XP`）。
3. **投喂白饭 (Feed Rice)**：
   * 点击控制栏或右键菜单「投喂白饭」：角色双手捧起大米饭大口咀嚼，头顶冒出满足的饱腹气泡。
4. **疯狂干饭 (Rice Frenzy)**：
   * 点击「疯狂干饭」：抱紧不锈钢盆暴风吸入，两只小脚丫欢快扑腾乱蹬。
5. **逗草玩耍 (Foxtail Play)**：
   * 触发逗鱼草 / 猫草玩具，角色向前飞扑并得意地摇晃尾巴。
6. **自动打盹与唤醒 (Sleep & Wake)**：
   * 45 秒无交互自动切入休眠打盹（播放打盹帧 `sleep-asleep.webp`）；
   * 单击桌宠立即唤醒（播放揉眼睛苏醒帧 `sleep-waking.webp`），并动态播发个性化问候语。

## 🎙️ 实时语音对聊与嘴型状态机闭环 (Voice Chat)

做面对面的实时语音互动，最具生命力的是**真实感与不抢话的从容感**。本客户端遵循严格的声学与状态机闭环：

### 1. 严格动作状态机闭环 (State Machine)
* **待机（Idle）**：悠闲浮动、眨眼、尾鳍轻摇；
* **倾听中（Listening）**：当麦克风检测到用户开口或插话打断时立即切入，状态球变绿。此时**双唇紧闭，杜绝普通 Demo 中角色在安静时不合时宜地乱动嘴巴**；
* **思考中（Thinking）**：当静音检测判定用户说完、等待大模型生成回复时切入，状态球变紫。此时**强制锁定双唇闭合**；
* **说话中（Speaking / Talk）**：收到音频合成与播报流时，嘴部图层自然跟随发音音节起伏张合（`whale-mouth-speak`），身体微幅欢快弹动；语音播完**立刻收口闭合**回到待机。

### 2. 随时插话打断 (Barge-in Interrupt)
* 在免唤醒（Hands-free）模式下，无论大肥鱼/伴侣正在说多么长的句子，只要你开口说话，系统毫秒级检测到声学能量（RMS）并即刻触发 `pipeline.Interrupt()`；
* 立即掐断本地发音，嘴唇瞬间收紧闭合，毫秒级无缝切入倾听（Listening），告别机械死板的播报感。

### 3. 根治抢答与丢字 (900ms 宽松静音判停)
* 传统语音助手默认 400-500ms 静音判定，用户换个气就会被强行插话抢答；
* 客户端将静音判定放宽到 **900ms**，留足说话停顿与思考空间，聊天节奏更自然从容。

### 4. 纯口语清洗引擎 (CleanSpokenText)
* 大模型回复往往包含 `**加粗**`、Markdown 语法、括号神态词（如 `（咽口水）`、`(微笑)`）或角色前缀（`大肥鱼:`、`回复:`）；
* 客户端内置纯口语清洗器，在推送给语音合成（TTS）前过滤非口语符号，根治朗读星号、括号与表情文字的问题。

## 🐾 桌宠形象与人设自由替换 (Swappable Pets & Personas)

**桌宠未必是大肥鱼，皮肤与人设完全独立解耦，支持随时随地热替换：**

### 1. 皮肤切换 (Skins)
在桌宠上右键单击或打开手账中枢，可自由选择：
* 🐋 **大肥鱼 (鲸鱼娘)**：原生高精度萌系立绘、实时嘴型闭合驱动、白饭与钢盆干饭序列帧；
* 🐱 **橘宝喵**：经典暖橘猫，活泼好动，拥有眨眼、跳跃、严格闭嘴倾听与思考帧；
* 🦊 **灵狐小九**：仙气赤狐，摇晃毛茸茸的大尾巴；
* 💧 **星灵露露**：软萌发光的小水滴星灵；
* 📦 **自定义导入**：支持一键导入外部符合 Codex Pet 规范的 `.zip` 皮肤包或目录。

### 2. 人格卡槽 (Persona Slots)
切换皮肤不会影响人格，切换人格亦不绑定皮肤。每个卡槽拥有独立的声音语速、系统提示词与醒来开场白：
* 🐋 **大肥鱼 (鲸鱼娘)**：性格温和开朗，爱吃白饭配鱼片、爱喝冰奶茶，两三句短句为主，末尾顺口抛出日常小反问。
  > *开场白：“哇！你终于把我叫醒啦！我是大肥鱼，今天想和我聊点什么呀？”*
* 🌙 **知心伴侣**：温柔共情、松弛随性，关注情绪，像老友闲聊。
  > *开场白：“你终于醒啦~ 今天过得怎么样，有什么想和我聊聊的吗？”*
* 💼 **高效幕僚**：干练极简、直入主题，拒绝废话。
  > *开场白：“效率顾问已就绪，随时准备为您提供决策与架构支持。”*
* 🔥 **毒舌损友**：幽默犀利、轻微损友吐槽，金句频出。
  > *开场白：“哟，总算想起我了？今天又被什么离谱的事情折磨了？”*

## 🛠️ 快速启动与构建 (Quick Start)

### 运行环境要求
* **macOS**：macOS 14+（Apple Silicon / Intel 均支持）
* **开发工具**：Go 1.21+、Xcode Command Line Tools（包含 `swiftc`）、Node.js 18+

### 一键运行或打包
```bash
# 1. 开发模式运行（自动编译原生 Swift ASR 并在本地启动桌宠）
make run

# 2. 一键打包并直接启动原生 macOS .app
make start

# 3. 仅构建 macOS 原生应用包 (生成 build/bin/Avatar.app)
./package_mac.sh
```

## ⚙️ 模型配置与自带 Key (BYOK Setup)

客户端大模型和语音服务支持完全解耦，配置文件位于 `~/.avatar/config.json`：

### 1. 本地大模型 (完全离线模式)
支持直接对接本机 Ollama 或 LM Studio：
```json
{
  "display_form": "pet",
  "pet_skin": "whale",
  "mode": "hands_free",
  "always_on_top": true,
  "llm": {
    "engine": "openai_compatible",
    "base_url": "http://127.0.0.1:11434/v1",
    "model": "qwen2.5:7b-instruct"
  },
  "tts": {
    "engine": "mac_say",
    "voice": "Ting-Ting",
    "rate": 180
  },
  "asr": {
    "engine": "native_mac",
    "locale": "zh-CN"
  }
}
```

### 2. 云端商业大模型 (自带 Key / BYOK)
兼容任何 OpenAI 协议端点（阶跃星辰 StepFun、通义千问 Qwen、DeepSeek 等）：
```json
{
  "llm": {
    "engine": "openai_compatible",
    "base_url": "https://api.stepfun.com/v1",
    "api_key": "你的_API_KEY",
    "model": "step-1o-turbo-vision"
  }
}
```
> **选型经验提示**：语音对话建议优先选用非推理（Non-Reasoning）短延时模型（如 `step-1o-turbo-vision` 或 `qwen2.5-7b`），可在 300-600ms 内直出首句，避免长思维链沉思导致冷场。

## ❓ 常见问题排查 (Troubleshooting)

1. **麦克风无声音 / 听不到我说话**：
   * 请在 macOS「系统设置 -> 隐私与安全性 -> 麦克风」中，确保已授权终端或 `Avatar.app` 使用麦克风；
   * macOS 原生离线听写需要在「系统设置 -> 键盘 -> 听写」中开启。
2. **大肥鱼说话时没有声音**：
   * 检查系统音频输出设备与音量；
   * macOS 默认使用系统原生高保真女声 `Ting-Ting`，可在手账抽屉中调节语速与发音人。
3. **想换成猫咪或其他皮肤**：
   * 在桌宠身上单击右键，选择「切换桌宠皮肤」->「橘宝喵」，大肥鱼将无缝切回猫咪，干饭、倾听闭嘴、发音说话依然全自动生效。
